# Board game graphing.

Represent games the most efficiently to draw "play-graphs".

## Overview.

**Games**:
- Tic-tac-toe.

**Tools**:
- `Python 3.14`;
- `Graphviz` and `dot`;
- `pyvis`.

## Installation.
Download the source code.
```shell
git clone git@github.com:Detroix23/board_game_graph.git
cd board_game_graph
```

Isolate in a virtual environment.
```shell
python -m venv .venv
# Unix based:
source ./.venv/bin/activate
# Windows:
./.venv/Scripts/activate
```

Install all dependencies (using `pyproject.toml`).
```shell
python -m pip install .
```

Ready to go !

## Running.
See the help for the full list of commands.
```
python ./src/tic_tac_toe_detroix23/ -h
```
